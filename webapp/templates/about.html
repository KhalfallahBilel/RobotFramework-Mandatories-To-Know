About RobotApp

A practice web application designed to help you learn Robot Framework test automation through hands-on exercises.

🎯
Mission
Provide a realistic, feature-rich web application to practice real-world test automation scenarios with Robot Framework.
⚙
Features
Authentication, CRUD operations, forms, tables, modals, API endpoints, dynamic content — all designed for testing.
🛠
Tech Stack
Built with Python Flask, vanilla HTML/CSS/JS. No database — all data is in-memory for easy resetting.
